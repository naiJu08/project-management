Voice Call Cross-Network Fix Verification

✅ Fixes Applied

  • ICE Transport Policy: Changed from 'relay' to 'all' - allows STUN + TURN candidates
  • ICE Server Credentials: Removed broken HMAC auth, kept only static credentials
  • handleAnswer Guard: Added check to prevent InvalidStateError
  • Audio Timing Fix: Only setup audio when ICE is actually connected
  • ICE Restart Fix: Removed invalid iceRestart flag on new connections

🔧 How to Test

  1. Open two different browsers (or devices) on different networks
  2. Both users log into the application
  3. User A calls User B
  4. Check debug console for these key indicators:

Expected Debug Output:

✅ ICE servers loaded: 8 servers
🎵 Remote audio track received - ICE state: connected
🔊 Setting up remote audio playback
✅ Remote description set from answer
✅ Call connected!
✅ Audio is playing

❌ Should NOT see:

❌ Error setting answer: InvalidStateError
❌ Connection failed
❌ No TURN servers working

🔬 Debug Tools

In the voice call window, use these buttons to diagnose:

  • 🔬 Test TURN: Verifies TURN servers can provide relay candidates
  • 🐛 Debug: Shows detailed connection logs
  • 🎤 Test Mic: Confirms microphone is working
  • 🔊 Play Remote: Forces audio playback if needed

🎯 Success Indicators

The fix is working when you see:

  • ✅ TURN server test shows "relay candidate received"
  • ✅ ICE connection state reaches "connected"
  • ✅ Remote audio track is received
  • ✅ Audio plays without clicking
  • ✅ No InvalidStateError in console
